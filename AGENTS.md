# AGENTS.md — Neuro-Mesh

## Quick Commands

```bash
# Build (all variants)
make clean && make -j$(nproc)          # Release (default)
make DEBUG=1 -j$(nproc)               # Debug (-g -O0)
make SANITIZE=1 -j$(nproc)            # ASan + UBSan

# Run
./bin/neuro_agent NODE_1               # Single node
./mesh_dashboard.sh                     # 5-node tmux grid
python3 orchestration/mesh_manager.py   # 5-node process manager

# Docker
docker compose -f docker-compose.yml build --no-cache
docker compose -f docker-compose.yml up -d

# Tests
make test                               # All unit tests
make fuzz                               # Fuzz targets (30s each)
# Individual test binaries in bin/:
#   test_pbft_consensus, test_meshnode, test_inference,
#   test_auditlogger, test_mitigation, test_proofchain,
#   test_telemetrybridge, test_pbft_perf

# Lint (CI uses these)
ruff check orchestration/ tools/        # Python
ruff format --check orchestration/ tools/
shellcheck -e SC1091,SC2034 *.sh tests/*.sh
hadolint Dockerfile                     # with --ignore DL3008,DL3013,DL3018,DL3042,DL3047,DL3049,DL3059
```

## Build Quirks

- **Compiler:** `clang++` by default (falls back to `g++`). CI matrix: `clang × {release, debug, sanitize}` + `gcc × {release, debug}` (gcc+sanitize excluded).
- **Include path:** `-I.` means all includes are project-root-relative: `#include "crypto/CryptoCore.hpp"`, not `#include "CryptoCore.hpp"`.
- **eBPF skeleton:** `kernel/sensor.skel.h` is auto-generated by `bpftool gen skeleton` during `make`. If `bpftool` is missing, the build copies the tracked version. Never edit `sensor.skel.h` by hand.
- **uWebSockets:** Cloned into `third_party/uWebSockets/` at build time (gitignored). CI pins to commit `8a1f3607f4d6cf3249fa6430543fc4134645c7b1` via `git -C`.
- **ONNX model:** `isolation_forest.onnx` is generated by `tools/train_iforest.py` during Docker build. Requires `scikit-learn` + `skl2onnx`.
- **No rtti/exceptions:** Built with `-fno-exceptions -fno-rtti`.

## CI Jobs (8 total)

| Job | What it checks |
|-----|----------------|
| `build` | Matrix: compiler × mode. Per-matrix `OBJ_DIR=obj-{compiler}-{mode}` |
| `docker` | Docker Compose up, event injection, dashboard health check |
| `static-analysis` | cppcheck + clang-tidy |
| `security-audit` | Banned functions, secrets, semgrep |
| `fuzz` | libFuzzer 30s per target (results not checked — `|| true`) |
| `python-lint` | `ruff check` + `ruff format --check` |
| `shell-lint` | `shellcheck` |
| `dockerfile-lint` | `hadolint` with `--failure-threshold warning` |

**CI ignores:** `DL3008, DL3013, DL3018, DL3042, DL3047, DL3049, DL3059` (version pinning warnings).

## Architecture Facts

- **P2P over UDP:** Nodes broadcast on `127.0.0.1:9999` (PBFT) and gossip telemetry on `:9998`. No central server.
- **WebSocket ports:** ALPHA=9000, BRAVO=9010, CHARLIE=9020, DELTA=9030, ECHO=9040. Override via `NEURO_WS_PORT`.
- **IPC socket:** `/tmp/neuro_mesh_{id}.sock` for commands (INJECT, ISOLATE, RESET, SHUTDOWN).
- **Safe list:** `PolicyEnforcer::add_safe_node()` prevents self-isolation. Never remove a node from the safe list in tests.
- **Signature binding:** PBFT signatures bind `(stage + target + evidence)` — cross-stage replay is prevented.

## Testing Notes

- GoogleTest is built from source in CI (`/usr/src/googletest`). Locally, needs `libgtest-dev` installed.
- Fuzz targets use `|| true` in CI — they don't block merges.
- `make lint` runs `clang-tidy` (slow, ~5min). CI wraps it with `|| true` in the static-analysis job.
- Integration test: `tests/integration_test.sh` — requires a running node.
- Stress test: `tools/test_stress.cpp` — builds separately, requires running mesh.

## Conventions

- **C++20**, clang-format with `.clang-format` (if present), `-Werror` in all builds.
- **Python:** `ruff` for linting/formatting. Scripts in `orchestration/` and `tools/`.
- **Shell:** `shellcheck` with `-e SC1091,SC2034`.
- **Commit messages:** Conventional Commits style (`fix(ci):`, `chore(docker):`, `feat:`, etc.).
- **Docker:** Multi-stage build. Runtime uses `tini` as init, runs as unprivileged `neuro` user.
